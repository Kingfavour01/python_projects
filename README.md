## Getting Started

1. Make sure Python 3 is installed:
   ```
   python --version
   ```
2. Clone the repo:
   ```
   git clone https://github.com/Kingfavour01/python_projects.git
   ```
3. Install dependencies:
   ```
   pip install PyQt5 pygame-ce qrcode Pillow requests
   ```
4. Run any project:
   ```
   python "area calc.py"
   ```

## Requirements

- Python 3.x
- `requests` — for API calls (`how to connect to api.py`, `weather app.py`)
- `PyQt5` — for GUI applications
- `pygame-ce` — for audio playback (`music player.py`)
- `qrcode` + `Pillow` — for QR code generation (`qr code.py`)
